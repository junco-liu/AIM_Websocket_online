# AIM 控制台

浏览器直连 VEX AIM 机器人的局域网控制台。单个 HTML 文件，零依赖，零构建，**不需要任何后端服务器** —— 网页只是静态资源，WebSocket 由用户浏览器直接连到同一局域网内的机器人。

协议参照 [VEX-Robotics/AIM_Websocket_Library](https://github.com/VEX-Robotics/AIM_Websocket_Library) 的 Python 客户端重新实现。

## 功能

- 输入机器人 IP 直接连接，实时显示电量与朝向
- 摄像头画面开关（`ws_img` 推送的裸 JPEG 逐帧渲染）
- 移动控制：方向盘按住即走、松开即停，或键盘 `WASD` 平移 / `QE` 转向 / `空格` 急停
- 灯光：单独或整体设置 6 颗灯珠颜色
- 踢球：轻 / 中 / 重

## ⚠️ 必读：为什么不能用 HTTPS 访问

AIM 机器人只提供明文 `ws://`，不支持 `wss://`。浏览器把从 HTTPS 页面发起的 `ws://` 连接视为 **blockable mixed content 直接拦截**，无法降级也无法自动升级。

所以本站**必须通过 `http://` 访问**。三种可行方式：

| 方式 | 做法 |
|---|---|
| **自定义域名 + 关闭 Enforce HTTPS**（本仓库采用） | 域名 CNAME 到 GitHub Pages，仓库 Settings → Pages 中**不勾选** Enforce HTTPS，之后用 `http://你的域名` 访问 |
| 手动放行 | 若已经打开了 HTTPS 版本，Chrome/Edge：地址栏图标 → 网站设置 → 不安全内容 → 允许 → 刷新。页面顶部会自动提示这三步 |
| 本地打开 | 下载 `index.html` 双击（`file://`），`ws://` 不受限 |

> `*.github.io` 在 HSTS 预加载列表中，**无法**通过 http 访问，只能走自定义域名或手动放行。

## 使用

1. 机器人与你的设备连入同一局域网（或直连机器人自身 AP，此时 IP 为 `192.168.4.1`）
2. 打开站点，输入机器人 IP，点「连接」
3. 点「开启」查看画面，用方向盘或键盘驾驶

## 协议要点

四个独立 WebSocket，均无鉴权，端口 80：

| 端点 | 用途 |
|---|---|
| `ws://<ip>/ws_cmd` | 命令。JSON 序列化后以**二进制帧**发送，严格一问一答 |
| `ws://<ip>/ws_img` | 画面。发单字节 `0x01` 开流、`0x00` 关流，之后每条消息为一整张 JPEG |
| `ws://<ip>/ws_status` | 遥测。**轮询式** —— 发 `0x01` 才回一包 JSON |
| `ws://<ip>/ws_audio` | 音频上传（本控制台未使用） |

连接后第一条命令必须是 `{"cmd_id":"program_init"}`。

单位为绝对值而非百分比：移动速度 mm/s（上限 200），转向 deg/s（上限 180）。左转为负值。

## 本地开发

```bash
python -m http.server 8099
```

## 安全提示

机器人自身没有任何鉴权。本页面对局域网内任何能访问到它的人开放机器人控制权。放在公网时若不希望被陌生人打开，请在前面加一层访问控制。
