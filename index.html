尚未连接机器人

确认设备与机器人在同一局域网，输入 IP 后点击「连接」。

  1. 把机器人开机，让它和这台设备连到同一个 Wi-Fi； 也可以直接连机器人自己的热点，此时 IP 是 192.168.4.1。
  2. 在上方填入机器人的 IP 地址，按「连接」。
  3. 浏览器若询问是否允许访问本地网络设备，请点允许。
  4. 连上后拨动下方图注条里的「画面」开关，即可看到实时画面。
